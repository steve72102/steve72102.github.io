# Steve 的個人網頁

簡約清爽的繁體中文個人網站，使用原生 HTML 與 CSS，無外部套件、追蹤程式或建置步驟。

## 修改內容

- `index.html`：自我介紹、創作練習、生活筆記與 GitHub 連結。
- `style.css`：配色、版面與手機樣式。
- 目前自我介紹、作品與筆記為示範文案，可自由替換；Steve 名字取自 GitHub 帳號。

## 預覽

直接用瀏覽器開啟 `index.html` 即可。

## GitHub Pages

在儲存庫 Settings → Pages 選擇 Deploy from a branch，分支選 `main`，資料夾選 `/ (root)` 後儲存。
若儲存庫名稱為 `steve72102.github.io`，網站網址為 `https://steve72102.github.io/`。
