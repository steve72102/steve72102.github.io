# 四個等級的八欄裝備設計規格

狀態：玩家已於 2026-10-31 確認[四張概念板](STYLE_MAP.md)的造型方向；八欄遊戲物品 ID、等級解鎖、前視 SVG 試穿與理解筆記研習已實作。概念圖保存為衣櫥預覽；每件透明前／側／後素材與跑步動畫仍待製作。各款裝備的外觀與品質等級分開，舊款可繼續培養並保留原造型。

## 共用穿戴關係

上衣與褲子貼身層先畫；鞋子覆蓋褲腳；外套覆蓋上衣但不吞掉褲子辨識線；披風獨立掛在肩／領口，不能與外套畫成一件；帽子隨頭部角度；配戴物固定在胸前或肩帶；手持物需有左右手持握錨點。每一欄最終需前、側、後三視圖與透明底、原始提示詞及人工修圖紀錄。概念板中的位置只供服裝辨識，不能直接切圖穿戴。

## Lv30 巴哈：單線行旅

主題是一條連續但不規則的細線，流過布片、口袋與書封；以現代野外採樣為用途。主色暖棕、米白、墨綠，低調銅色只用於少量五金。

| 欄位 | 具體造型／材料 | 穿戴與三視圖重點 |
| --- | --- | --- |
| 外套 | 及膝啡色拉鍊防護外套、平面多口袋、啞光帆布；一條細線由肩延至下擺 | 肩線與背包背帶錯開；側視確認口袋厚度，後視讓細線連貫 |
| 披風 | 墨綠短直邊肩披，可獨立拆下 | 披風落在外套肩縫外，後視不遮滿背部線條 |
| 上衣 | 米白素色棉襯衣，袖口可捲 | 領口在外套內可見，側視無多餘荷葉邊 |
| 褲子 | 暖灰啡色耐磨收納褲，窄長口袋 | 小腿活動空間清楚，後視保留完整褲型 |
| 鞋子 | 低筒綁帶步行鞋，分片皮布鞋面 | 正側視呈現鞋尖、鞋底與褲腳交界 |
| 帽子 | 軟質野外帽，簡單帽檐 | 不蓋住眼鏡或眉毛，後視有帽圍 |
| 配戴物 | 抽象單線別針，無音符形狀 | 小尺寸仍能辨識一筆線條，固定於外套胸前 |
| 手持物 | 素面採樣筆記本，彈性束帶 | 左右手持握位置都可用，書頁不能出現假文字 |

## Lv40 舒曼：記憶書房

以柔軟回折與留白表現反覆思索，衣著比 Lv30 輕、更安靜。主色霧紫、燕麥、暖灰；避免古典戲服、荷葉邊與大量緞帶。

| 欄位 | 具體造型／材料 | 穿戴與三視圖重點 |
| --- | --- | --- |
| 外套 | 霧紫有袖短外套，圓角下擺、柔軟棉麻 | 前視保留簡單鈕扣，側視有自然垂墜，後視無燕尾 |
| 披風 | 淺紫短圍肩，以小扣固定 | 可和外套分開裝卸，不變成圍巾文字圖案 |
| 上衣 | 燕麥色寬鬆棉襯衣、乾淨袖口 | 領口清楚，避免禮服褶飾 |
| 褲子 | 暖灰直筒褲，低對比細縫 | 以布料墜感辨識，不沿用 Lv30 的野外大口袋 |
| 鞋子 | 淺色低跟便鞋、深色薄底 | 側視呈現低鞋跟，不做高靴 |
| 帽子 | 素面針織軟帽 | 針紋與耳部碰撞要檢查，無徽章和流蘇 |
| 配戴物 | 小型書籤別針，折頁抽象形 | 固定在外套胸口，不與稀有度邊框混淆 |
| 手持物 | 霧紫回想手札，素面封面 | 記錄冊可合起／打開，內頁不生成可讀假文字 |

## Lv50 莫札特：幾何序曲

以交錯、對應與收束形成現代裁片，與歌劇戲服無關。主色奶油白、鈷藍、炭灰，少量陶紅提供節奏停頓。

| 欄位 | 具體造型／材料 | 穿戴與三視圖重點 |
| --- | --- | --- |
| 外套 | 有袖短版結構外套、交疊三角門襟、啞光斜紋布 | 前側後三面幾何裁片必須接得上，不能只畫正面圖案 |
| 披風 | 短而平整的藍白披片，獨立肩扣 | 不能與外套肩片合併，側視保持薄厚度 |
| 上衣 | 奶油白素面高領衣 | 和外套門襟形成留白，後頸不露假領片 |
| 褲子 | 炭灰俐落長褲，一側少量配色裁片 | 維持可行走褲管，不用舞台緊身褲 |
| 鞋子 | 奶油白低鞋、藍灰簡線 | 側視鞋底薄且耐走，不做舞鞋 |
| 帽子 | 低輪廓分片布帽 | 以裁片而非金飾辨識，與眼鏡避讓 |
| 配戴物 | 小型幾何量測徽記 | 胸前固定點，縮小後仍見交錯結構 |
| 手持物 | 可折頁學習圖冊，深藍封面 | 書冊展開與合起都能持握，不放歌劇場景或符號 |

## Lv60 海頓：四線晴空

以四條布料通道的交織做輕量可修復設計，並維持現代戶外學習服的實用性。主色鼠尾草綠、雲白、石板灰與天然亞麻。

| 欄位 | 具體造型／材料 | 穿戴與三視圖重點 |
| --- | --- | --- |
| 外套 | 圓角寬鬆拉鍊外套，可替換縱向布條，局部修補縫 | 後視交代四條布料的起終點，不能和 Lv50 尖角西裝相似 |
| 披風 | 圓弧短肩披，四線短垂片 | 可獨立拆卸，後視不遮擋外套修補結構 |
| 上衣 | 雲白素色針織上衣 | 領口和袖口可見，避免花紋過滿 |
| 褲子 | 寬鬆可活動工作褲，局部四線分片 | 側視膝部活動量明確，修補縫線合理 |
| 鞋子 | 可修補低筒綁帶鞋、耐磨鞋底 | 前側後呈現鞋面拼片與鞋帶，與 Lv50 便鞋區分 |
| 帽子 | 軟質帆布帽、圓檐 | 可折收，與 Lv30 野外帽以更輕的輪廓區分 |
| 配戴物 | 四條細線交會的小徽記 | 不做鳥或翅膀圖案，固定胸前 |
| 手持物 | 可替換封套的分層研習冊 | 手持錨點與翻頁狀態，封面只保留原創抽象線條 |

## 後續驗收

每套八欄需先檢查穿戴組合與無披風／無外套的分別預覽；再做品質標記的 UI 驗證。老存檔遷移、同款升級、抽獎獎項與多人同步依 [遊戲裝備設計稿](../../game/EQUIPMENT_DESIGN.md)執行，不能由這份概念規格推定已完成。
