# 思維冒險 Mind Quest

遊戲網址：https://steve72102.github.io/game/

獨立的 HTML / CSS / JavaScript 學習遊戲。無登入、無 ChatGPT API、無外部程式依賴、無付費項目。取消 ChatGPT 訂閱不影響已發布或下載的遊戲。

## 遊玩

每日閱讀知識卡領取普通裝備。每題每天首次答對可得 10 XP，每累積 5 題換取 1 張星願券。裝備加成最多每題 6 XP。答錯不扣分，並加入錯題清單。每天以 Asia/Taipei 時區換日，不要求連續登入。

寶箱機率：普通 60%、稀有 30%、史詩 9%、極品 1%。連續 29 抽沒有極品，第 30 抽必得；抽到極品即重置。各稀有度的 3 件裝備等機率。重複裝備獲得 10/20/40/80 XP。無真實金錢價值。

## 備份與離線

在「存檔與說明」匯出 JSON 存檔。進度只存在瀏覽器 localStorage，不會上傳；不同裝置、瀏覽器、網站或 file:// 離線版的儲存空間不一定相同。清除瀏覽資料可能移除進度。

離線 ZIP 完整解壓縮後，開啟 index.html 即可玩。不需安裝 Node.js、Python 或 ChatGPT。網頁版本的 service worker 首次連線載入後會快取遊戲檔案，但瀏覽器可能自行清除快取；長期保存請下載 ZIP 與存檔。

## 題庫與限制

3,221 題，來自使用者「我的思維資料夾」108–115 年 47 組主題教學筆記的結構化來源：藥劑生物藥劑、藥理藥化、藥物分析與生藥學。僅收錄可取得完整文字、單一答案與解析的題目，排除已辨識的缺圖、爭議題與缺少筆記的題目；115-1 藥物分析與生藥學尚未轉入。計算分類為關鍵字輔助判斷。每題附筆記來源，原始 PDF 不隨遊戲上傳。

供國考複習，不作臨床處方依據。原筆記仍可能有誤；疑義請回看正式試題與答案。

## 安全

無外部 script、分析追蹤或帳戶服務。使用 CSP、textContent、存檔格式與數值白名單驗證。僅接收最大 2 MB 的 JSON 備份，不執行其內容。這是單人本機遊戲，時鐘和存檔可被玩家修改，並非防作弊系統。

網頁不能安裝或取代系統防毒軟體。請保持瀏覽器、作業系統與既有防毒軟體更新。

## 維護

直接修改 app.js / style.css / engine.js。更新靜態檔案時同步修改 sw.js 的 CACHE 版本，讓離線版本更新。瀏覽器在舊分頁關閉後切換新版本。game/ 可部署在 GitHub Pages 的子目錄，不需建置。

核心邏輯測試：`node --test tools/engine.test.cjs`（在原始專案根目錄執行）。
