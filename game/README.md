# 思維冒險 Mind Quest

遊戲網址：https://steve72102.github.io/game/

獨立的 HTML / CSS / JavaScript 學習遊戲。無登入、無 ChatGPT API、無付費項目。單人模式無外部連線依賴，雙人模式使用隨遊戲附上的 PeerJS 1.5.5。取消 ChatGPT 訂閱不影響已發布或下載的遊戲。

## 遊玩

每日閱讀知識卡領取普通裝備與 80 金幣；金幣也可在商城領取，每日只領一次。每題每天首次答對可得 10 XP，每累積 5 題換取 1 張星願券。裝備加成最多每題 6 XP。答錯不扣分，並加入錯題清單。每天以 Asia/Taipei 時區換日，不要求連續登入。

寶箱機率：普通 60%、稀有 30%、史詩 9%、極品 1%。連續 29 抽沒有極品，第 30 抽必得；抽到極品即重置。各稀有度的 3 件裝備等機率。重複裝備獲得 10/20/40/80 XP。無真實金錢價值。

## 備份與離線

在「存檔與說明」匯出 JSON 存檔。進度只存在瀏覽器 localStorage，不會上傳；不同裝置、瀏覽器、網站或 file:// 離線版的儲存空間不一定相同。清除瀏覽資料可能移除進度。

離線 ZIP 完整解壓縮後，開啟 index.html 即可玩。不需安裝 Node.js、Python 或 ChatGPT。網頁版本的 service worker 首次連線載入後會快取遊戲檔案，但瀏覽器可能自行清除快取；長期保存請下載 ZIP 與存檔。

## 題庫與限制

3,221 題，來自使用者「我的思維資料夾」108–115 年 47 組主題教學筆記的結構化來源：藥劑生物藥劑、藥理藥化、藥物分析與生藥學。僅收錄可取得完整文字、單一答案與解析的題目，排除已辨識的缺圖、爭議題與缺少筆記的題目；115-1 藥物分析與生藥學尚未轉入。計算分類為關鍵字輔助判斷。每題附筆記來源，原始 PDF 不隨遊戲上傳。

供國考複習，不作臨床處方依據。原筆記仍可能有誤；疑義請回看正式試題與答案。

## 安全

程式檔案全部由本站提供，沒有分析追蹤或帳戶服務。使用 CSP、textContent、存檔格式與數值白名單驗證。僅接收最大 2 MB 的 JSON 備份，不執行其內容。單人進度仍在本機，時鐘和存檔可被玩家修改，並非防作弊系統。雙人模式限制封包大小、驗證暱稱、裝備、題號、回合與答案順序；使用 SHA-256 承諾後揭露答案，避免在傳輸協定中先看到對方選擇再作答，但題庫與答案本來就在瀏覽器，不能視為伺服器防作弊。

網頁不能安裝或取代系統防毒軟體。請保持瀏覽器、作業系統與既有防毒軟體更新。

## 維護

直接修改 app.js / style.css / engine.js。更新靜態檔案時同步修改 sw.js 的 CACHE 版本，讓離線版本更新。瀏覽器在舊分頁關閉後切換新版本。game/ 可部署在 GitHub Pages 的子目錄，不需建置。

核心邏輯測試：`node --test tools/engine.test.cjs`（在原始專案根目錄執行）。


## V2：雙回合打怪、個人週賽與補給商城

每場固定兩回合、每回合三題，兩回合完成後結算。可挑戰紙頁小怪 Lv.3、符文守衛 Lv.10、迷霧術士 Lv.20、鑽晶巨龍 Lv.35；所有難度直接開放。

- 基礎攻擊：18 + min(角色等級, 20) × 2 + 裝備攻擊（0/8/18/32）+ 同科裝備 6。
- 生命：90 + min(等級, 20) × 5 + 裝備生命（0/10/25/45）。裝備減傷：0/2/4/7。
- 單回合傷害：基礎攻擊 × 答對數 + 22 × 答對數² + 全對獎勵 30；第二回合有答對時再加上第一回合答對數 × 6。
- 敵方反擊：max(0, 敵方攻擊 - 本回合答對數 × 12 - 裝備減傷)。
- 總傷害達敵方耐久且生命大於 0 即獲勝。Lv.1 無裝備、六題全對可造成 594 傷害、剩 39 生命，足以擊破耐久 520 的巨龍。
- 裝備與等級在開戰時鎖定；戰鬥題目仍累積原有的每日經驗、星願進度與錯題紀錄。

### 每週個人積分賽

台北時間每週一 00:00 換季。銅階 0、銀階 600、金階 1,800、鑽石階 3,600 分。這是本機個人進度，與雙人友誼對戰分開計分，沒有全球排行榜或防作弊伺服器。

答對每題 20 分，勝利額外 80/150/220/300 分，全對獲勝再加 80 分。每隻怪每天只取最佳紀錄，重打只補發超出原紀錄的積分與金幣。每題答對獲 3 金幣基準，獲勝再加 15/25/40/60；同樣只發最佳紀錄差額。

換週後首次開啟遊戲自動結算上一個有紀錄的賽季：銅/銀/金/鑽石各 60/120/240/400 金幣。保留最近 8 個參賽賽季。上一週尚未結束的對戰可繼續學習，但不計入本週積分與金幣。

### 商城與補給

補給券 1 張 40 金幣、3 張 100、10 張 300；星願券 1 張 120 金幣。補給券只可在每回合開始前使用，1 張解鎖該回合 3 題的答案與解析；開始前可以重看且不重複扣券。第二回合需要另一張，開始作答後不能使用或再次打開預讀。已使用的券在放棄對戰後不退回。

依使用者目前選擇，**只開放遊戲金幣商城，刷卡尚未啟用**。頁面不收集卡號，也不模擬付款成功。未來真正收款需先選擇商家金流、確認商品與售價，並使用後端驗證付款、處理訂單與商品發放；不得只依網址參數或前端狀態發放已付款商品。

### 舊存檔相容

V2 使用 `mind-quest-save-v2` 儲存鍵。首次載入若沒有 V2 存檔，會讀取原 `mind-quest-save-v1`，保留題目、等級、裝備與星願券，為新增系統建立空白進度。舊鍵保留，避免仍開著的 V1 分頁覆寫 V2 的金幣與比賽進度。備份 JSON 包含新 `arena` 欄位；舊備份也可匯入，但會以空白商城與週賽進度取代現有新增系統。

戰鬥與商城邏輯位於 combat.js；畫面位於 combat-ui.js 與 combat.css。測試：`node tools/combat.test.cjs`，連同 `node tools/engine.test.cjs` 共 23 項。


### 補給知識預習

補給以知識卡呈現：概念標題、完整題意、這題應選的完整內容、判斷解析與記憶重點。明確的「選C」「所以B」等代號會展開為選項文字，避免只記字母。保留完整題意，避免將否定題的錯誤敘述誤當一般知識；也可展開對照全部選項。AUC、BCS、維生素與受體名稱等學科縮寫不會被一律刪除。


## V2.1：雙人線上友誼對戰

在「雙人對戰」輸入暱稱與科目。自動配對會尋找同科目正在等候的真人；沒有人時持續等待，不使用機器人。也可建立 10 碼房間，由朋友在另一台裝置開啟網站、輸入房號加入。加入房間採用房主的科目。

兩人回答相同 6 題、分為 2 回合，兩回合總傷害較高者獲勝，相同為平手。沿用打怪的知識傷害公式（沒有怪物反擊），等級與裝備鎖定在配對當下。雙方準備好後開始；每題先鎖定答案，兩人交卷後公布答案。完成解析後雙方同意才換題。補給券每回合開始前可使用一次，提供完整題目、正確內容與解析，準備後不能重看。使用過的券不退回。

準備最多 180 秒；每題作答與解析等待各最多 120 秒。連線失去回應、等待超時、關閉／重整頁面或離開都會結束本場，不自動判對方勝。單題已取得的經驗與錯題保留。友誼賽不增加每週打怪積分或額外勝負金幣，沒有全站排名與帳號驗證。

### 連線與長期使用

- GitHub Pages 維持現有網址。程式沒有 ChatGPT API、登入或訂閱檢查。
- 點擊連線才建立 PeerJS Cloud 的 HTTPS/WSS 連線（0.peerjs.com:443）；Google STUN 用於 WebRTC 網路協商。無鏡頭或麥克風。
- 透過 WebRTC data channel 交換暱稱、等級、裝備、題號、答題狀態；不傳整份存檔、錯題清單或筆記。對手及網路服務可能取得連線所需的網路位址。
- 自動配對以每科目的版本化等待 ID 撮合兩位玩家；握手完成後釋出等待 ID，後續玩家可接著配對。私人房號為隨機 50-bit 代碼，開戰後關閉新連入。
- 免費 PeerJS Cloud 無本專案的服務保證，忙碌或故障會影響配對。此版未設定 TURN 中繼，因此部分對稱 NAT／嚴格企業網路無法互連，介面會提示重試或換網路。未驗證所有跨網路組合。
- 單人模式與離線 ZIP 不依賴此連線服務。ZIP 的雙人入口會引導使用網站版。
- 日後如需大量同時在線、可靠的跨網路連線與正式排名，需自建配對／TURN 與具有伺服器判分及帳號驗證的後端；不是單純開啟排行榜即可做到。
