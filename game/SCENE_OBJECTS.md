# 背景原景物件的實體互動

## 實作方式與範圍

本地精修版本 `20261101-refinement-r3`。已閱讀並人工查看五種大廳與四種教室的原圖，將前一版每個室內場景額外放入的通用桌／左右椅移除。九種背景對應十八個室內 scene，各樓層沿用該棟相同建築風格，各科教室維持不同內景。

重建採取三層：清理後的建築背景、獨立可移動物件，以及以實際圖像位置設定的碰撞／站立面。這是已完成資產與人工校準的 2.5D 遊戲物件，不是執行時辨識任意照片、也不是把每個像素自動變成 3D。

`scene-objects.js` 是唯一場景物件登錄來源，供尋路、推動、站立、墜落、渲染及連線驗證共用。每件物品有穩定 ID、材質、質量、摩擦、可移動性、地面足跡、支撐面與繪圖錨點。原圖中重複於不同樓層的物件，其當次互動狀態仍以完整 scene ID 分隔，換樓層不互相污染。

## 材質與行為

| 材質 | 互動結果 |
| --- | --- |
| 玻璃 | 可被碰推；離開桌面支撐後下落並摔碎；角色直接踩落亦可破裂 |
| 陶瓷 | 陶盆與陶研缽可碰落摔碎，使用陶片外觀 |
| 紙 | 筆記與書本可被推落，保留完整物件，沒有玻璃碎片 |
| 木 | 桌椅可推、可跳上；木盤可被推落並保留 |
| 金屬 | 可移動椅凳／儀器按質量與摩擦移動，落地後保留；連牆／懸掛設施固定 |
| 石 | 固定石台、石長椅不會被推走；小石研缽是重物，可掉落但不產生玻璃碎片 |
| 植物 | 根植景觀固定；獨立植栽是否碎裂由容器材質決定，葉子本身不產生玻璃碎片 |

- 桌面道具記住 `support`；推桌時仍在桌上的物品跟著移動。掉到地板的物品與碎片不會被原桌帶走。
- 道具離開桌面後有短暫落下動畫。玻璃／陶器碎片保留 60 秒；踩到時短暫傷勢約 8 秒後恢復。
- 碎片消失後留下移除狀態，物品不會在原位立刻重生。此狀態維持本次場景房間生命週期，不寫入永久學習存檔。
- 紙、木、金屬及石質小物落地後留在現場，之後仍可推動。固定設施不受動態家具封包改寫。
- 傷勢、碎裂等規則不以新手教學彈窗預告；玩家可在探索時自行發現。互動查看固定物件須主動按既有互動鈕／E／Enter，經過不自動開窗。
- 新樓層先套用該樓層共享物件狀態，再從該場景實際 `arrival` 桌／長椅前尋找合法位置。已推動的物件、樓梯及出口需一起檢查。
- 畫面遮擋用同張乾淨背景的固定前面遮罩，不重畫一張重複工作台。動態家具與角色依地面深度排序，跳躍高度沿用既有站立邏輯。

## 資產與來源

`assets/scene-objects/` 含九張乾淨背景（WebP）及一張透明 PNG 圖集。九張圖均以使用者公開 repository 對應原圖編輯；圖集為該專案新生成、配合原景風格的十六種獨立物件。原始建築構圖保留，透明道具再按物件登錄復原。

`PROVENANCE.json` 記錄公開原圖 Git blob、生成後 SHA-256、尺寸、格式與操作；`generation-prompts.json` 保存實際提示詞。原圖不是法律授權的替代品；新增資產未使用外部作品、學校徽章、品牌、名人或遊戲 IP 作為額外參考。服裝的音樂靈感沒有使用錄音或歌詞。

圖集的實際輸出不是等寬整齊的 4×4 裁切。各物件的 sourceRect 與腳底錨點已明確測量；CSS 保留長寬比，避免切掉椅腳、把花盆頭裁到下一格或把燒瓶拉寬。不要把這些數值改回通用 25% 網格。

## 連線與效能

家具與道具沿用 PeerJS 主持端同步。新增穩定索引式 wire encoding，包含所有十八個 scene 的道具／家具狀態；內部 API 保持具名資料方便驗證。接收端仍檢查索引、數量、有限數值、支撐歸屬、材質、地板、碰撞與計時範圍，不因壓縮而放寬封包上限。

封包上限仍為 65,536 bytes，並同時驗證字元長度與 UTF-8 真正 byte 長度。六十個模擬角色含四 byte 字元名稱、完整八欄裝備及全場景狀態的測試，只證明正常滿載封包能通過，不證明六十真人的手機 FPS、WebRTC 可靠性或身份可信度。

動態物件 DOM 與外觀快取重用，靜止資料不反覆改樣式；每次 restore 的共用幾何只建一次，沒有跨請求保存未驗證可變資料。尋路保留完整碰撞檢查，效能量測附於交付包；測到的 Node CPU 耗時不能當成瀏覽器幀率。

## 驗收與限制

自動測試位於 `photo-scene-layout.test.cjs`、`material-objects.test.cjs`、`photo-scene-ui.test.cjs`、`photo-scene-network.test.cjs` 及既有移動／家具／大廳測試。圖像重建檢視另產生九室預覽及碰撞覆層；它們取自實際圖集、登錄與 UI 樣式，屬來源重建圖，不是實際瀏覽器截圖。

發布前必須在 Safari／Chrome 與真實觸控裝置驗收站立點、遮擋、跳躍、杯子跌落、碎片消失、樓層切換及多端同步。遠景微小物件、所有歷史美術及藥學教材沒有因這次測試而自動完成內容或原創性審核。
