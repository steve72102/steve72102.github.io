# Scene object art

Build-time project assets for refinement-r3. Runtime code uses only the generated WebP / PNG files. No image-generation service, credentials or ChatGPT subscription is required to play.

- Nine clean plates preserve the supplied project architecture while removing loose objects assigned to dynamic layers.
- props.png is an original transparent 16-object atlas. Use the measured source rectangles and anchors in scene-objects.js, not equal 4×4 cells.
- PROVENANCE.json records source Git blobs, output hashes, dimensions and operations.
- generation-prompts.json preserves the actual generation/edit instructions.
- ../../SCENE_OBJECTS.md explains geometry, materials, boundaries and tests.
- No external artwork or music recording was used as an additional reference. Historical repository art was supplied by the user; this record does not certify rights for all earlier assets.

The assets are part of a reviewable local patch. Their presence is not evidence of GitHub Pages deployment.
