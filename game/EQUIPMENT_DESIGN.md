# 裝備與風格設計稿（2026-10-31）

狀態：Lv30–90 七級概念圖已獲玩家確認；八欄裝備、等級衣櫥、十人前視混搭試穿圖與理解筆記研習已接入遊戲程式。Lv30–60 另有[十人版型概念板](../artifacts/music-fashion/CAST_VARIANTS_30_60.md)。原有抽獎獎項與機率未改。前視試穿圖為原創 SVG 示意，側視、後視及每件透明動畫素材尚未製作。

Lv70 的莫札特《安魂曲》〈落淚之日〉＋印度服裝語彙見[「餘光檔案」](../artifacts/music-fashion/LEVEL70_REQUIEM.md)。Lv80 的張雨生〈天天想你〉＋英國 1990 年代街頭服、Lv90 的 ATEEZ〈BAD〉＋夏威夷 aloha wear 見[兩級概念規格](../artifacts/music-fashion/LEVEL80_90_CONCEPTS.md)。三套均已加入免費等級衣櫥。

## 已確定的方向

- 每隔 10 個角色等級開放一個**新風格系列**。Lv10 是以巴洛克時期服飾語彙為靈感、重新設計的學院風格；Lv20 是當代學院；Lv30–60 改以四首指定古典樂作抽象視覺轉譯，仍維持現代服裝語彙；四張概念圖已確認，正式穿戴素材依此製作。
- 風格是外觀與剪裁，不決定品質。裝備圖示的邊框、星記及文字標示**當前品質**；不能只靠顏色辨識。
- 解鎖新風格不會強迫換裝。玩家可保留喜歡的舊款，透過學習材料培養它，使舊款仍能跟上角色成長。
- 衣著、配戴物和手持物都可以培養。書籍、藥瓶、羅盤、沙漏、鑑別鏡、月燈等既有知識物品應列為手持物候選；不需要設計刀劍或付費強化石。
- 新圖案與剪裁須原創。巴洛克是歷史風格參考，不複刻現存遊戲、動漫、品牌或受保護角色的具體造型與標誌。

## 穿戴欄位

| 欄位 | 範圍 | 與舊遊戲的關係 |
| --- | --- | --- |
| 外套 | 穿在上衣外的有袖外層 | 許願池中名稱為外套、長衫、禮衣的款式 |
| 披風 | 無袖披風、披肩、斗篷 | 舊 `coat-dawn`、`coat-herb`、`coat-star` 及名稱為披風／披肩的許願裝 |
| 上衣 | 襯衣、背心、學院上裝 | 新欄位 |
| 褲子 | 長褲、裙褲等下身衣著 | 新欄位 |
| 鞋子 | 鞋、靴 | 舊 `boots` 欄位 |
| 帽子 | 帽、頭飾 | 舊 `hat` 欄位 |
| 配戴物 | 徽章、胸針、護符等 | 舊 `badge` 欄位 |
| 手持物 | 書籍及既有知識器具 | 現有 `equipped` 知識裝備應遷入此欄 |

一件物品只佔一個欄位；外套與披風可以分開選擇。手持物維持原有學科加成，不改成武器傷害或現金獎品。裝備欄先展示空位與名稱，未定稿的風格不製作假造型。

各級的布料主色可以由玩家選擇，品質仍只顯示在邊框、星記和文字上。Lv60 使用可修復的現代材料與研究工具，不加入武器、機甲或付費感特效。所有圖案使用原創的藥草、筆記、量測與幾何元素，避開現成品牌、校徽及作品角色。

品質沿用遊戲的普通、稀有、史詩、極品四階。原始抽獎機率和獎項身分保持不變；培養只提升**目前持有的裝備品質／效果**，不回頭改寫抽獎結果。品質提示可用灰、藍、紫、金邊框搭配文字與符號；服裝本身的布料配色由風格決定，不用整套染成品質色。

## 以學習材料培養裝備

1. 每日第一次答對同一道題時取得「理解筆記」。同一天重答不重複給；原本的 XP、星願券與金幣規則不變。
2. 可在裝備詳情選「投入理解筆記」，培養指定款式。複習曾答錯的題目可作為額外材料來源，但必須避免同一道題反覆刷取。
3. 培養提高該款的研習階段與能力，不改名稱、造型、風格解鎖等級或已穿戴欄位。新風格可以直接使用，舊風格也可追上當前角色階段；培養不得越過角色目前等級。
4. 目前背包把同款物品合併計數。首版以「同款共用研習階段」相容既有存檔；重複獲得同款不會重置已投入的筆記。若日後要讓同款的不同件分別培養，才另做逐件物品遷移。
5. 材料花費與能力上限在實作前用既有戰鬥數值測試調整，避免升級後使答題或戰鬥失衡。餵養失敗時不得扣材料、裝備或金幣。

## 舊存檔與正式版驗收

- 保留所有既有物品 ID、持有數量、許願收據及主線進度。遷移穿戴欄位時，舊披風轉披風，舊靴轉鞋子，舊徽章轉配戴物，舊知識裝備轉手持物；不能把同一件裝備複製成兩件。
- Lv10／20 的新服裝仍按原概念待製作，不臨時套用其他等級的衣服圖片。
- 驗證舊存檔匯入、背包容量、八欄穿脫、喜愛舊款培養、等級限制、單雙人戰鬥數值、離線存檔、雲端同步及許願後的存檔復原。
- 正式發布前檢查多人協定、Service Worker 離線包與下載版；不把本次前視示意誤稱為已完成的側視、後視或逐格動畫。

## 原創服裝素材製作流程

目前可用的 `imagegen` skill 適合製作服裝概念圖、透明背景的角色穿戴圖與變體；若反覆製作本遊戲的八欄裝備，可用 `skill-creator` 將下列規則做成專用 skill。不要直接安裝來源不明、宣稱「保證無侵權」的服裝 skill。

1. 只以本遊戲已保存來源的原創角色和已確認的裝備設計稿作為圖像參考。歷史風格、現代服裝用途與一般剪裁可作為概念參考；不拿其他遊戲角色、品牌型錄或影視截圖要求重製。
2. 每次先寫明等級、八欄中要製作的部位、剪裁、材料、原創花紋及手持學習物。品質色只放在遊戲介面的邊框與標記，不把同一套衣服換色當成新風格。
3. 概念圖經確認後再逐件製作透明素材；記錄提示詞、輸入參考、生成日期、版本與人工修改。每個部位需有前／側／後視角及穿戴定位，避免只靠一張全身概念圖裁切成裝備。
4. 發布前人工檢查圖案、標誌、文字、角色輪廓與現成作品是否過於相似；發現疑似商標、校徽、角色特徵或無法確認來源的素材就重新設計。保留原始檔與修改記錄。
5. 這些步驟能降低風險，不能保證法律上零侵權；正式商用前如有具體疑慮，針對個別設計再做權利查核。
