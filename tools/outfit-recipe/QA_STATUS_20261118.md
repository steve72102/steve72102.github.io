# Professor COMMON / wish-river-coat isolated QA

**Status: pending art. Not released to the game.** Base `main` was `ccfbf31215510bcfed59854e4014a37479e8db2d`. The exact-loadout runtime fix is isolated commit `215fc64`.

## Reproduction

The published `crossline-shirt` pass contains the old green coat, and `crossline-pants` contains coat tails and pale cutout fringes. `professor-river-coat-v1` borrows both passes, so changing only the blue jacket cannot correct the outfit. A green shoulder cape is also visible when the real loadout equips `fruit-pineapple-cape`; it must not be silently hidden or swapped.

## Candidate and batch check

`stage-professor-shirt.py` exports the existing painted cream blouse and its alpha mask into an isolated candidate directory. It removes coat contamination in the underlayer but is **not yet a distinct new shirt design**. `clean-professor-pants.py` derives a non-destructive trouser mask from the eight existing atlases. It reduces side tails and light gray fringe, but the waist and leg edges still need art correction when worn alone. All source PNG/WebP files remain unchanged.

Run `node tools/outfit-recipe/export-professor-qa-plans.cjs <plans.json>` followed by `python tools/outfit-recipe/render-professor-qa.py <plans.json> --output <dir>` to render 11 layouts × 64 cells = 704 actual pass selections. Add `--preview-isolated-v2` to the exporter for the candidate image paths. The 11 layouts include the eight transparent slot passes, COMMON full, river full, and a mixed loadout. Source decode, dimensions, alpha, cell boundary, isolated speck and light neutral edge heuristics are recorded in `professor-qa-report.json`. The original run decoded 104 source images and rendered 704 cells; the candidate run also rendered 704. These are local composites, **not game screenshots or artistic approval**.

The river full and pants slot contact sheets are retained in `qa-evidence-20261118/`. Visual review found the candidate closer to the desired layered outfit, but the pants waist remains visibly cut in standalone view. The cape and hat have no standalone painted profile in this loader. These are release blockers.

An isolated localhost server and in-memory professor save fixture were prepared for real-game validation. HTTP index, garment override and app script requests returned 200. Chrome UI verification stopped when Computer Use could not establish the browser URL confidently; no live run screenshot or movement acceptance was obtained. Do not treat the contact sheets as real-game evidence.
